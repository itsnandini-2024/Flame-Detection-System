🔥 Flame Detection System
📌 Project Overview
The Flame Detection System is an Arduino-based embedded system designed to detect fire hazards in real time using a flame sensor module. The system provides immediate visual alerts through LEDs and serial monitor output, helping in early fire detection and safety monitoring.
This project demonstrates practical implementation of sensor interfacing, embedded programming, and real-time monitoring using Arduino.
🎯 Objective
1)To design and implement a low-cost fire detection system that:
2)Detects flame using an  flame sensor
3)Provides instant alert signals
4)Monitors sensor output via Serial Monitor
5)Enhances basic fire safety awareness
🛠️ Components Used
a)Arduino Uno
b)Flame Sensor Module
c)LED (Red/Green for indication)
d)Resistors (220Ω for LED)
e)Breadboard
f)Jumper Wires
g)USB Cable
h)DHT11
⚙️ Working Principle
The flame sensor detects infrared light emitted by fire.
When flame is detected:
LED turns ON (alert indication)
Message is displayed on Serial Monitor
When no flame is detected:
LED remains OFF (normal condition)
The Arduino continuously reads digital/analog signals from the flame sensor and processes the input to determine fire presence.
